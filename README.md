# E-Commerce Sales: SQL Data Analysis

## Project Overview
SQL analysis on an e-commerce dataset of 1,200 orders using MySQL 
Workbench to extract business insights through structured queries.

## Tools Used
- MySQL Workbench — SQL querying and analysis

## Queries Covered
- SELECT, WHERE, ORDER BY, GROUP BY
- Aggregations: COUNT, SUM, AVG, ROUND
- Date functions: YEAR(), MONTH(), STR_TO_DATE()
- CASE WHEN for conditional analysis

## Key Findings
- Total Revenue: 1,264,761.96
- Chair generated highest product revenue
- Cancelled orders had highest revenue loss at 276,395
- Instagram top acquisition channel with 259 orders
- January 2023 was strongest single month at 56,685
- 891 orders used coupon codes vs 309 without
